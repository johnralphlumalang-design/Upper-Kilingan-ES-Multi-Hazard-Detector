# 🚨 Upper Kilingan E/S Multi-Hazard Detector

A real-time emergency alert and early-warning web application designed specifically for **Upper Kilingan Elementary School (UKES)**. This system monitors environmental hazards (DepEd 4H Heat Index, PAGASA Typhoons, PHIVOLCS Earthquakes) and campus emergencies (Fire, Active Intruders) to provide immediate protocols and safety guidance for faculty, staff, and students.

---

## 🌟 Key Features

* **DepEd 4H Heat Index Engine:** Automatically tracks ambient/feels-like temperatures and categorizes risk into **HAYO** (<27°C), **HINAY** (27–32°C), **HINGA** (33–41°C), and **HINTO** (≥42°C) with corresponding learning modality alerts.
* **PAGASA Typhoon Monitor:** Real-time updates on Tropical Cyclone Wind Signals (TCWS Signal Nos. 1 to 5) and automatic class suspension rules.
* **PHIVOLCS Earthquake Alert:** Intensity tracking (Levels I to VIII) with immediate **"Duck, Cover, & Hold"** emergency action screens.
* **On-Campus Emergency Triggers:** Immediate full-screen override alerts for **Fire Hazards** and **Active Shooter / Intruder** situations with designated evacuation pathways.
* **Interactive Hazard Simulator:** A built-in testing dashboard allowing administrators to test and verify emergency alert scenarios.
* **Web Audio API Sirens:** Simulated emergency alarm tones for critical alerts directly inside the app.

---

## 📋 System Setup & User Roles

Upon launching the app, users configure their profile through a 3-step setup wizard:
1. **User Role Selection:** Faculty/Teacher, Student/Parent, or DRRM Safety Staff.
2. **Campus Building Zone:** Grade 1–3 Building, Grade 4–6 Building, or Admin/Principal's Office.
3. **Emergency Permissions:** Mock toggles for background location geofencing and critical audio overrides.
